AFM04 / AFM05 NN seed initialization definition
===============================================

Purpose
-------
This note records how NN seeds should be described in AFM04 and AFM05, and how
this relates to the original HNODECB biology examples.


Recommended short phrase
------------------------
The most accurate short phrase is:

  seed-controlled random initialization

If the stochastic perturbation itself needs to be emphasized, a slightly more
specific phrase is:

  seed-controlled random noise perturbation

The phrase "random noise perturbation" is not completely wrong, but it is less
precise because the main reproducibility mechanism is the seed. Different
seeds do not mean that an already trained or already selected network is being
perturbed afterwards. Instead, each seed deterministically generates a different
initial neural-network parameter set under the same architecture and
initialization settings.


Conceptual formula
------------------
For a fixed architecture and fixed initialization settings, the initial NN/KAN
parameters for seed s can be written schematically as:

  theta^(s) = theta_base + alpha * epsilon^(s)

where:

  theta^(s)     = initial NN/KAN parameters generated by seed s
  theta_base    = fixed base initialization structure shared across seeds
  epsilon^(s)   = random perturbation/draw generated by seed s
  alpha         = perturbation amplitude, such as an initialization or
                  noise-scale factor

Thus, across different seeds, theta_base is conceptually the same, while
epsilon^(s) changes. In ordinary MLPs this is often expressed more simply as:

  theta^(s) ~ D_init

where the seed controls a reproducible draw from the same initialization
distribution.


Relation to the original HNODECB biology examples
-------------------------------------------------
The original HNODECB biology examples follow the same idea in spirit:

  different random seeds -> different reproducible NN initializations

In those examples, the neural networks are Lux dense MLPs. The seed controls
the Lux initialization of dense-layer weights and biases, typically through
Glorot-style initialization.

In AFM04 and AFM05, the neural component is KAN-based. The same principle is
used, but the concrete mechanism is different: the seed controls the
reproducible KAN initialization under fixed KAN architecture, grid settings,
normalizer/support settings, dtype/device, and noise-scale settings.


Thesis-ready wording
--------------------
Short version:

  NN seeds were used to generate seed-controlled random initializations.

Slightly more explicit version:

  Each NN seed deterministically generated a distinct initial neural-network
  parameter set under the same architecture and initialization settings.

KAN-specific version:

  Each NN seed deterministically generated a distinct KAN initialization, with
  the architecture, grid settings, and initialization scale kept fixed across
  seeds.


Important distinction
---------------------
The difference between two seeds should not be described as a non-reproducible
or post-hoc perturbation of the same trained model. It is a reproducible
initialization difference.

Therefore:

  better:  seed-controlled random initialization
  acceptable if emphasizing epsilon: seed-controlled random noise perturbation
  less precise alone: random noise perturbation
