AFM03 作弊边界约定（当前用户口径）

日期：2026-03-31

以下项目，当前明确“不算作弊”：

1. 数据读入后按 true contact 的 first-contact 时刻截到 post-contact horizon。

2. g_nn 的使用与更新，不算作弊。

3. 使用 W1 / W2 / W3 窗口（包括基于当前流程中的窗口生成逻辑），不算作弊。

4. initial condition 与上帝视角监控项，不算作弊。

5. 使用 true contact 派生出的样本级时间权重 / 掩码，不算作弊。
   这包括：
   - contact_loss_weight 与 noncontact_loss_weight 的时间点加权；
   - 用 contact_idx = findall(contact_mask) 决定哪些时刻计入 x2dot 误差。

当前仍需单独警惕、并继续按代码审计确认的，是：

- 未知真值信号是否被直接作为训练目标进入 loss。
- 未知真值信号是否以标签/掩码/加权方式直接进入 train process。

备注：

- 本文件只记录当前用户明确给出的“作弊边界”口径。
- 若后续口径变化，应同步更新本文件。
