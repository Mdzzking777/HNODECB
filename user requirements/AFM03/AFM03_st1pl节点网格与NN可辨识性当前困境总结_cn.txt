AFM03 st1pl 节点网格与 NN 可辨识性当前困境总结

一、当前 st1pl 的搜索设定

1. 当前 stage1pluslight 不再使用完全随机的 ks0 / cs0 全局搜索，而改成：
   - ks, cs 在给定边界内做对数网格划分
   - 每个 node 对应一个固定的 (ks0, cs0)
   - 每个 node 叠加固定数量的 NN 初始化 seed bank

2. 目前继承自 stage1 的 architecture 是：
   - layers = 0
   - nodes = 1
   - hidden = 2
   - 总参数量 = 8

3. 这意味着：当前 st1pl 里，NN 不是一个“中等复杂度网络”，而是一个极小的 shallow MLP。

4. 需要特别强调：
   - ks, cs 的 node 现在是结构化的，不再随机
   - 但 NN weights 仍然是随机初始化样本
   - 只是这种随机现在是固定 seed 驱动的可复现伪随机
   - 同一个 seed_bank 编号在所有 node 上复用同一套初始 weight vector

二、当前最核心的困境

1. 我们已经逐渐看到一个现象：
   - 某些 trial 可以把 ks, cs 拉到比较接近真值
   - x1, x2 以及由它们诱导的 loss 可以很低
   - x3 reconstruction 也可能并不差
   - 但 NN error / F_contact error 却长期居高不下

2. 这说明一个重要问题：
   当前低 loss 并不自动意味着“学到了正确的接触力映射”。

3. 因而当前真正的困境已经不是：
   “optimizer 还不够努力”
   而更像是：
   “我们当前的 architecture + loss + observability 组合，是否根本不支持得到一个低 NN error 的解”

三、当前需要区分的两种可能性

第一种可能：
存在某个 weight vector，
它能够同时满足：
   - ks, cs 很准
   - x1 / x2 / x3 恢复很好
   - NN error 也很小

但当前 objective 没有把优化推向这个解。

第二种可能：
在当前 architecture（L0N1）下，
根本不存在这样的 weight vector，
也就是说：
   - 即使 mech 和状态层面都恢复得很好
   - NN 对真实 F_contact / F_ts 的逼近仍然无能为力

目前日志现象并不能证明第一种一定成立，反而让第二种怀疑变得越来越合理。

四、为什么这个怀疑是合理的

1. 当前 architecture 过小
   - L0N1 只有 8 个参数
   - hidden 只有 2 个单元
   - 这对 AFM 中状态到接触力的映射来说，容量可能过低

2. 当前 NN 学的不是一个简单平滑反应项
   - 我们的 F_ts / F_contact 带有接触开闭、分段行为、局部尖锐变化等特征
   - 其时间信号复杂度比许多 biology examples 中的未知项更高

3. 当前观测并不直接锚定接触力
   - F_ts 是由第二个方程间接得到
   - x3 不是直接观测量
   - 当前 loss 也没有直接把 F_contact error 作为训练项
   - 因此即使状态轨迹对了，力通道仍可能不唯一

4. 当前 NN error 只是 monitor
   - 它被打印、被比较、被可视化
   - 但并不是当前 objective 中的直接优化目标
   - 所以“低 loss + 高 NN error”在当前系统里并不矛盾

五、与 biology examples 的对照结论

1. 原作者在三个 baseline biology examples 中使用的网络都不算大，但它们的任务形式更友好：
   - Lotka-Volterra: 2 -> 16 -> 16 -> 2
   - Glycolysis: 2 -> 16 -> 16 -> 1
   - Cell Apoptosis: 6 -> 8 -> 8 -> 1

2. 它们的共同特点是：
   - NN 只替代少数缺失导数项
   - 输入变量是精挑出来的状态子集
   - 目标更像平滑的反应速率 / 交互项

3. 与之相比，我们当前 AFM 的困难在于：
   - NN 需要承担接触力映射
   - 而该映射对小网络来说可能更复杂
   - 因此不能简单因为 biology examples 里“小网络可行”，就推断 AFM 的 L0N1 也足够

六、当前 st1pl 的 node-grid 设计价值

1. node-grid + fixed seed bank 的价值，不是直接证明存在好解，而是让问题变得更可诊断：
   - 能比较 node 之间的 mech 区域差异
   - 能比较同一 node 下不同 NN 初始化的波动
   - 能区分“坏的是 mech node”还是“坏的是 NN seed”

2. 当前这种设计至少能帮助回答：
   - 好区域是否成片出现
   - 同一 node 下最优 / 中位 trial 是否仍普遍存在高 NN error
   - 若是，则更支持“architecture / identifiability 限制”而不是“随机没抽中”

七、当前最值得坚持的判断

1. 当前困境不应再被简单解释成：
   - 训练不够久
   - optimizer 不够强
   - retry / lr 还没调到位

2. 更准确的说法应当是：
   - 当前 architecture 可能太小
   - 当前 observability 对 F_contact 的锚定可能太弱
   - 当前 objective 对 NN force 误差的驱动力可能不够直接
   - 三者叠加后，使得“低 loss + 高 NN error”成为完全可能的结果

八、当前最需要验证的问题

当前最关键、最值得单独验证的问题不是：
   “还能不能把 loss 再降一点”

而是：
   “在固定或接近真实 ks, cs 的情况下，
    当前 L0N1 architecture 是否存在一个能够把 F_contact / F_ts error 真正压低的 weight vector”

如果答案是否定的，
那么当前问题的主因更可能是：
   - architecture capacity 不足
而不是：
   - 纯粹优化没做好

九、当前结论

目前我们真正面对的，不只是一个优化问题，而是一个联合问题：
   - architecture 是否足够
   - observability 是否足够
   - identifiability 是否存在

在这个前提下，st1pl 的 node-grid 搜索不只是为了找更小的 loss，
更是为了帮助判断：
   “当前 AFM 任务下，L0N1 是否有能力同时恢复 mech、state 和正确的接触力映射。”

十、当前 Datageneration / DMT_KV 中使用的硬接触 F_ts 数学公式

为避免与后续 softplus / 软化版本混淆，这里记录当前 Datageneration/DMT_KV 中
用于生成可视化时域图的硬接触定义。

1. 先定义 tip-sample separation：

   s(t) = d + x(t) - y(t)

   其中：
   - d = dist
   - x(t) = tip displacement
   - y(t) = sample displacement

2. 定义压痕量：

   delta(t) = max(-s(t), 0)

3. Hertz 力定义为：

   F_Hertz(t) = (4/3) * E* * sqrt(R) * delta(t)^(3/2)

4. 当前硬接触净接触力 F_ts 定义为：

   若 s(t) <= 0：

      F_ts(t) = F_Hertz(t) - F_ad

   若 s(t) > 0：

      F_ts(t) = 0

5. 等价地，可写成单个分段表达式：

   F_ts(t) =
   {
      (4/3) * E* * sqrt(R) * (-s(t))^(3/2) - F_ad,   s(t) <= 0
      0,                                              s(t) > 0
   }

6. 这个硬接触定义的一个直接后果是：
   - 接触刚开始时，delta 很小，F_Hertz 约为 0，因此 F_ts 约等于 -F_ad
   - 接触中部，delta 变大，F_Hertz 上升，因此 F_ts 被抬高
   - 接触结束前，delta 再次变小，F_ts 又回到接近 -F_ad

   因而在时域图上，单个接触 burst 可能呈现边缘双峰 / 双谷结构。
