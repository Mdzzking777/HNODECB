AFM03：stage2light_windowed 中 NN raw 形状问题与 step2b 优先方案总结

日期：2026-04-01

一、当前观察

1. 在以下图中：
   - logs/stage2_step2a/local/windowed/visualization/afm_param_stage2light_windowed_03_nnraw_wpred_grid.png
   可见 NN raw output 在三个窗口里都比较平滑，形状近似低频正弦/余弦模板。

2. 在以下图中：
   - logs/stage2_step2a/local/windowed/visualization/afm_param_stage2light_windowed_03_fcontact_grid.png
   最终的 F_contact pred 与 true F_contact 已经相当接近，尤其接触开关结构主要由 w_pred 给出。

3. 因此，当前最合理的解释不是“NN 完全没学到力学信号”，而是：
   - 模型参数化把复杂的接触开关结构交给了 w_pred；
   - NN raw 更多承担“接触期间的平滑幅值模板”角色；
   - 所以 NN raw 本身不一定会长得像最终 Fts/F_contact。

二、关键背景

1. 目前我们已经使用较大的 NN 结构，以及 st1pl 中网格化的全局随机搜索，能够在当前参数化下找到全局极小值附近的候选点；随后再用 stage2light_windowed 的 AMSGrad，以及 step2b 的 L-BFGS，对这些候选做更精细的连续优化。

2. 因而，当前阶段的核心问题已经不再主要是“能否找到更好的 ks/cs/NN 初值”，而是：
   - 在当前参数化 F_contact = g_nn * NN_raw * w_pred 下，
   - 即使 loss 继续下降，NN raw 是否仍然只学到一个平滑模板，
   - 而不能直接逼近 Fts/F_contact 那种更复杂的局部形状。

3. 这也是为什么现在应优先把 step2b 视为“诊断优化上限与参数化分工”的实验，而不是先验认定它必然会把 NN raw 变成复杂 Fts 形状。

三、目前提出的三步思路

1. 先继续做 step2b，尝试把 loss 进一步逼小，看 NN raw 是否开始学到更细的局部形状。
2. 如果 step2b 之后 NN raw 仍然保持平滑模板，则下一轮从头开始做 st1pl -> st2lw，但移除 NN raw * w_pred 里的 w_pred 乘子，直接让 NN 去承担完整 Fts/F_contact 形状。
3. 如果去掉 w_pred 后仍不足，则再尝试更大 NN，甚至尝试 EQL。

四、step2b 的当前特点

1. step2b_windowed 现在按窗口继承当前 stage2light_windowed 的 best 结果，而不是重新随机全局搜索。
   - 每个窗口只继承 1 个 best 初值；
   - multi-start 已暂时禁用。

2. 继承内容包括：
   - ks / cs；
   - p_net；
   - NN 结构；
   - nn_gain（与 st1pl / st2lw 的 g_nn 语义保持一致）。

3. 优化器目前是本地 L-BFGS。
   - 默认跳过 Adam；
   - 直接从当前 stage2 结果进入二阶法细化。

4. 早停/退出策略目前包括：
   - plateau early-stop：连续 5 个 epoch 内 loss 改变量低于当前 loss 的 1%；
   - good enough loss：loss < 1e-10；
   - 达到 max_lbfgs_iters；
   - 或 line search / 数值过程出现非有限失败而退出。

5. 步长策略不是 Adam 式学习率调度，而是 L-BFGS 自带的 line search alpha。
   - 每一步先试 alpha = 1.0；
   - 不接受时按 0.5 回退；
   - 直到接受或低于最小阈值。

6. 如果将来没有找到可继承的 stage2 结果，step2b 会显式打印：
   - “无法找到可继承结果，将使用随机起点！”
   但在当前正常链路下，预期应直接继承 stage2 best，而不是走随机起点。

五、当前建议：先做第 1 步

我认为第 1 步值得先做，而且风险最低。

理由如下：

1. 它不改模型结构。
   - 这意味着如果 step2b 已经能显著降低 loss，那么你可以先确认“是否只是当前优化还没压到足够低”。

2. 它是一个很好的判别实验。
   - 如果 step2b 之后 loss 继续明显下降，但 NN raw 仍然是平滑模板，而 F_contact pred 继续变好，
     则说明问题主要不是优化不充分，而是参数化分工本身决定了 NN raw 不必像 Fts。
   - 反过来，如果 step2b 一压 loss，NN raw 就明显开始长出复杂细节，
     那么说明第 3 点“当前优化还不够到位”确实占主要地位。

3. 它比直接改掉 w_pred 更便宜。
   - 去掉 w_pred 会改变模型归因方式，结果解释也会一起变。
   - 先做 step2b，可以先判断是否有必要走到那一步。

六、对第 1 步的预期

我目前的预期是：

1. step2b 很可能会进一步降低 loss；
2. 但 NN raw 未必会因此显著变成复杂、尖锐、接近最终 Fts 的形状；
3. 更可能发生的是：
   - 幅值更准；
   - 相位更准；
   - 接触期间细部略有修正；
   - 但“平滑 raw + 门控 w_pred -> 复杂最终 F_contact”这个总体分工仍然保留。

也就是说，第 1 步更像是“验证优化上限”，而不一定是最终解决“NN raw 为什么不像 Fts”的方法。

七、执行顺序建议

建议按以下顺序执行：

1. 先基于当前 stage2light_windowed_03.jld 跑一次 step2b_windowed。
2. 比较 step2lw 与 step2b 在三个窗口中的：
   - train loss / val loss
   - F_contact 对齐情况
   - NN raw 形状
   - x1/x2dot/x3 相关误差
3. 如果 step2b 后：
   - loss 明显下降，但 NN raw 仍平滑，
     则优先进入第 2 步：移除 w_pred 再重跑全链路。
4. 如果 step2b 后：
   - loss 已接近极限，F_contact 也已很好，
     但你仍然想要“NN raw 本身可解释地长成 Fts”，
     那么这更像是结构设计目标问题，而不是优化问题，仍应进入第 2 步。
5. 只有在第 2 步之后仍不满意，再做第 3 步：更大 NN / EQL。

八、当前结论

当前最合理的策略是：

先做第 1 步，但把它明确定位为“诊断优化上限”的实验，而不是先验认定它一定能让 NN raw 长成复杂 Fts 形状。

如果第 1 步证明：
   - 更低 loss 仍然不会改变 NN raw 的平滑本质，
那么就应当把主因判定为模型参数化分工，而不是简单的优化不足。
