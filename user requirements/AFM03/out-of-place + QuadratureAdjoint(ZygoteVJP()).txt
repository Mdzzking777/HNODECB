Purpose
Record the current status of the AFM03 route based on:
- out-of-place RHS
- `QuadratureAdjoint(autojacvec=ZygoteVJP())`

This file focuses on:
- what this route solved,
- why it mattered historically,
- what its runtime limitations were,
- and what role it should currently play.

====================================================
1. Why this route was important
====================================================

1. It was the first tested unified-route replacement that restored reduced AD-vs-FD agreement.
- It matched FD closely for:
  - `p_mech`
  - sampled `p_net`

2. It therefore changed the interpretation of the old Stage2light failure.
- The old formal route was no longer just "poorly tuned".
- It became clear that the old route was formally unreliable.

3. This qzygote route was the first route that looked both:
- mathematically much more trustworthy,
- and compatible with the desired single formal-route philosophy.

====================================================
2. What this route achieved
====================================================

1. It repaired the correctness picture in reduced diagnostics.
- Reduced AD-vs-FD for `p_mech` was aligned.
- Reduced sampled `p_net` AD-vs-FD also aligned much better than the old route.

2. It proved that AFM03 was not limited to the old ReverseDiff-based formal route.
- A new adjoint-family replacement existed that could recover reduced gradient correctness.

====================================================
3. What this route failed to deliver
====================================================

1. It was computationally expensive in formal-precheck-style backward.
- In reduced formal-precheck profiling, active backward was about:
  - `185.3 s`

2. It therefore did not solve the runtime crisis.
- It improved correctness,
- but it did not provide a practical full-scale formal-training route.

3. It was later surpassed by gausszygote as the preferred unified candidate.
- gausszygote remained expensive,
- but it was still somewhat better than qzygote in reduced formal-precheck runtime.

====================================================
4. How this route should now be interpreted
====================================================

The current interpretation is no longer:
- "this is the production route"

It is now:

1. a reduced correctness reference,
2. a fallback diagnostic route,
3. the first route that demonstrated that reduced AD-vs-FD agreement could be restored,
4. but not the primary formal-training candidate.

====================================================
5. Current engineering role
====================================================

This route should now mainly be treated as:

- correctness oracle,
- fallback diagnostic reference,
- historical turning point in the AFM03 debugging process,
- but not the preferred production backend.

That is because:

- it fixed the correctness diagnosis,
- but it did not fix the runtime practicality problem.

====================================================
6. One-sentence conclusion
====================================================

`out-of-place + QuadratureAdjoint(ZygoteVJP())` was the first AFM03 route that restored reduced AD-vs-FD credibility for both `p_mech` and sampled `p_net`, but its formal backward cost was too high, so it should now be treated mainly as a correctness oracle / fallback rather than the preferred production Stage2light route.
