1. 问题概述：3维系统 + 部分可观测（state-level partial observation）
   ============================================================

系统状态为：

 x1(t) tip 位移（可观测）
 x2(t) tip 速度（可观测）
 x3(t) sample motion  样品内部形变自由度（完全不可观测，hidden state）

观测向量为：

 [x1(t), x2(t)]   （任何时刻都只观测这两个）
 x3(t) 在任何时刻都没有直接测量

这是“维度缺失”的 partial observation，不是“时间上稀疏采样”。

当前验证阶段我们固定：

 x3(0) = 0   （synthetic 阶段可接受且明确的先验）

============================================================
2) 分段动力系统（非接触  接触）
===================

系统是混合动力学（hybrid dynamics），分为 Non-Contact 与 Contact 两段。请按下面这种“可读公式格式”理解与实现。
 s = d+x1-x3;
delta = -s;
{A) Non-Contact (非接触)}

x1dot = x2;
x2dot = (F_d*cos(ωd*t)-k*x1-c*x2)/m;
x3dot = ks/cs * x3;


{B) Contact (接触)}

{Hertz 接触力模型：}
F_hertz = 4/3 * Estar * R^0.5 *delta^1.5

x1dot = x2;
x2dot = (F_d*cos(ωd*t) - F_adh +F_hertz - k*x1-c*x2) / m;
x3dot = (F_adh - F_hertz - ks*x3) / cs;




============================================================
3) 各项物理意义 + 已知未知（当前阶段设定）
=========================

我们当前阶段（synthetic validation）的已知未知定义非常严格，请按下面表执行：

【状态】

 x1(t) tip displacement，可观测（已知观测）
 x2(t) tip velocity，可通过x1求得（已知观测,注意其平滑性）
x2dot(t) tip acceleration, state-space equation的LHS，可通过x1求得（已知观测,注意其平滑性）
 x3(t) sample motion  internal deformation，不可观测（未知，需要估计）
 x3dot(t) 因为 x3 未知，x3dot 自然未知（由估计模型产生）

【已知物理参数（当前阶段全部视为已知常量或已知输入）】

 m 等效质量(tip effective mass），已知
 k tip 等效刚度（tip effective linear stiffness），已知
 c tip 等效阻尼（tip effective linear damping），已知
 F_d drive force amplitude，已知
 ωd drive angular frequency，已知
 R tip radius，已知
 d total distance，已知
 F_adh adhesion force（范德华黏附力，VdW adhesion），已知

【当前阶段未知参数】

 Estar effective modulus（Hertz 模型中的 E），未知（需要估计）
 ks sample stiffness parameter（样品内部等效弹性参数），未知（需要估计）
 cs sample damping viscous parameter（样品内部等效黏性参数），未知（需要估计）

【模型项（当前阶段：结构已知，但含未知参数hidden state）】

 F_hertz : Hertz contact model force

  其中 Estar 未知，x3 未知；R、d、x1 已知（x1为观测），且整个F_hertz的方程框架已知

4) 方法论红线（必须严格遵守）
================

允许：

 使用 ground-truth x3(t)、ground-truth F_hertz 仅用于：

  1. 画图对比（visualization）
  2. 计算误差指标（evaluation）
  3. 做 baseline reference（上界对照）


禁止（视为作弊）：

 任何训练优化中直接使用 ground-truth x3(t) 或 ground-truth 接触力
  （不能进入 cost function  loss；不能用于梯度更新；不能用于参数拟合；不能用于初始化时强制对齐）
 不能把问题改成“监督学习 x3”或“监督学习接触力”而绕开 partial observation 的本质

一句话原则：
Ground truth 只能用于评估，不能用于学习。

以下问题是你可能会犯的错误，请注意：
1. loss项的监督，要完整包含LHS已知项，对x1, x1dot, x1ddot进行监督（如果在当前阶段sample motion x3已知，则也要作为监督项），并同时对contact和non-contact区域进行监督。请设立sanity check，在保证未知参数正确以及未知公式项正确的情况下，测试loss是否接近0.
2. 请保持数据生成和数据调用的一致。由于本模型是piecewise function，分为non-contact和contact区域，那么交界处的可微性就很重要，因此是一个难点。同时，当用x1以及其导数作为监督项时，请注意生成这些导数的方式，以及后续loss的调用，主代码的计算是否也和导数生成的方式保持着一致。
