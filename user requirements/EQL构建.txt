# Task: Build EQL model for F_ts learning with sigmoid gate

## Goal

Construct an Equation Learner (EQL) model to learn the analytical expression of tip-sample force F_ts.

* Input: real system states (x1, x2, x3)
* Output: symbolic expression of F_ts
* Training: physics-informed loss (state + x2dot)

---

## Clarified Purpose of This Task

This task is **not** intended to be directly plugged into AFM03 at this stage.

Instead, this is a **separate workbench experiment** in another repository, where an existing EQL implementation is already available and will be slightly modified for this purpose.

The main purpose is:

* assume we have **fully observed data**
* test whether EQL can **analytically recover a precise F_ts expression**
* use this as a controlled structural-identifiability experiment

So the question here is not:

* “can EQL immediately replace the AFM03 NN in production?”

but rather:

* “under ideal observation conditions, can we recover a clean analytical F_ts law at all?”

Also note:

* the target F_ts in this workbench experiment is **not required to be identical to AFM03 Scenario03**
* this document therefore describes an **independent symbolic-learning experiment**, not a direct AFM03 deployment plan

---

## Target Physics Structure

We assume F_ts follows a DMT-like structure but written in unified (non-piecewise) form using a gate:

F_ts(s) =

* -AR / (6 * (H(s - a0) * (s - a0) + a0)^2)

 + (1 - H(s - a0)) * (4/3) * Estar * sqrt(R) * (a0 - s)^(3/2)

Where:

* s = function of (x1, x3)  (already defined in system)
* H(.) is a gate (to be approximated by sigmoid)
* a0 is a learnable threshold
* AR, Estar, R can be learned or fixed depending on implementation

---

## Contact Switching Mechanism

The contact transition may be implemented by either:

1. a learnable sigmoid-type smooth switch
2. or a Heaviside-type switch

Therefore, the experiment does **not** require introducing a separately named external “gate” module.

What is required is simply that the contact/non-contact transition be representable inside the expression class used by the workbench.

One possible smooth form is:

g(s) = sigmoid(β * (s - a0))

Where:

* β is a learnable scalar (gate sharpness)
* a0 is learnable
* sigmoid(x) = 1 / (1 + exp(-x))

If a hard transition experiment is also desired, H(s - a0) may be tested separately as a comparison baseline.

---

## Final Model Form

F_ts(s) =

* -AR / (6 * (g(s)*(s - a0) + a0)^2)

+ (1 - g(s)) * (4/3) * Estar * sqrt(R) * (a0 - s)^(3/2)

---

## EQL Requirements

1. Use existing EQL framework (already implemented)

2. Extend operator library to include:

   * addition (+)
   * multiplication (*)
   * division (/)
   * power (x^n, especially n = -2, 3/2)
   * sqrt
   * exp
   * sigmoid (IMPORTANT: may be treated as primitive operator if the workbench uses smooth switching)

3. If sigmoid is used, it should support:
   sigmoid(β * x)
   where β is learnable

4. Model should explicitly learn:

   * s from (x1, x3)
   * a0
   * β
   * coefficients (AR, Estar, etc. if not fixed)

---

## Inputs / Outputs

Input:

* x1, x2, x3 (time series)

Output:

* F_ts(x1, x2, x3) as symbolic expression

---

## Loss Function

Use existing physics-informed loss:

L = L_state + L_x2dot

Where:

* L_state: error between predicted and true states
* L_x2dot: error in acceleration dynamics

(Already implemented in system — reuse directly)

---

## Important Constraints

1. Do NOT use explicit piecewise / if-else
2. All expressions must be differentiable (via sigmoid gate)
3. Prefer minimal symbolic complexity (EQL objective)
4. Encourage sparsity if supported

---

## Expected Outcome

Model should discover a structure close to:

F_ts ≈ adhesion_term + gated_hertz_term

and ideally recover:

* inverse-square law for non-contact
* (a0 - s)^(3/2) for contact
* sigmoid gate around s = a0

---

## Notes

* β controls transition sharpness:
  large β → near hard gate
* Keep β trainable
* Avoid numerical instability (clip exp if needed)
