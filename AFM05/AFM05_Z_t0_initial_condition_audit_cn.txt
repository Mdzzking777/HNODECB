The earlier time 0.602492 ms is not the current operational t0. In the stored
source coordinate system it has x1 = +68.654348490 nm. Keeping both that time
and the downward-negative convention would require a coordinated sign change
of the source state channels; the current implementation does not do that.

2. Confirmed stale settings that were corrected

- The source NPZ had a correct AFM05_initial_condition array but stale
  AFM05_x3_init and x3_init scalar fields inherited from Z = 63.771 nm.
  Both now equal +11.807905232 nm.
- Gain-reference metadata still described the old source window beginning at
  index 114943. It now describes index 151372 through 157660, stride 16,
  394 sampled points, 315 training points, and 79 validation points.
- The generated-dataset cache previously checked only pixel_tag and window
  start. It now also checks the dataset signature, source filename, Z, source
  initial index, and the x3(t0) formula.
- st1pl resume previously checked only mode/span/stride. It now also checks the
  actual window manifest, including time and index boundaries.
- st1pl and prest2 PowerShell launchers now clear stale stage-specific
  environment variables before writing the current formal settings.
- The obsolete window comment saying the loss window starts later than the
  entry initial condition was corrected. Both begin at the current t0.

5. Guard and downstream behavior

- The st1pl absolute-x1 guard is calculated from the current selected window,
  not from an old W0 value. In the formal launcher its multiplier is 1.0.
- The online x1 reconstruction guard is explicitly disabled by the formal
  st1pl launcher.
- st2l uses the same current data and normalizer. Its launcher already clears
  stale stage2 environment variables.
- Epoch-0 preparation calls the same stage2 prepare_data path and therefore
  follows the same dataset, window, initial condition, and normalizer.
- Step3 is archive-bound by design: it reads the exact time grid, initial state,
  normalizer, known parameters, and model from the chosen st2l archive. An old
  archive remains self-consistent with its old experiment and is not silently
  rewritten to the current baseline.
