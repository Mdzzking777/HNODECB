标题：
从 Adam-only + hard step guard 到 Adam + Trust Region → L-BFGS + Strong Wolfe 的训练框架构思

背景：
当前 KFT 中，KAN 作为未知 tip-sample interaction force Fts 的替代模型，并不是通过 Fts 标签直接监督，而是通过 ODE rollout 后的动力学一致性 loss 进行间接优化。因此，训练过程不仅受 KAN 表达能力影响，也受到 ODE-constrained loss landscape、step size、optimizer dynamics 和 numerical sensitivity 的共同影响。

目前使用的 Adam/AMSGrad + hard step guard retry 框架存在两个问题：

1. Adam/AMSGrad 阶段虽然具有较好的前期探索能力，但在 ill-conditioned loss landscape 中可能收敛缓慢、震荡，甚至停留在较差 basin。
2. hard step guard retry 只能根据 L_new 是否大于 L_old 来拒绝更新，属于非常粗糙的 step acceptance rule。它可以防止破坏性更新，但也可能过于保守，使模型难以穿过狭窄下降通道或进入更优 basin。

Rathore et al. 在 “Challenges in Training PINNs: A Loss Landscape Perspective” 中指出，physics-informed loss 的训练困难很大程度来自 differential operators 导致的 ill-conditioning，并且 Adam + L-BFGS 通常优于单独 Adam 或单独 L-BFGS。作者在实验中对 Adam learning rate 进行 grid search，并在后期切换到 L-BFGS with strong Wolfe line search。:contentReference[oaicite:0]{index=0}

本文的方案不是完全复制该流程，而是在不提前进行 Adam learning-rate grid search 的条件下，构造一个更适合当前 KFT 的训练框架：

Adam/AMSGrad + Trust Region
→
L-BFGS + Strong Wolfe Line Search

核心目标：
用 trust region 替代当前 hard step guard retry 机制，使 Adam/AMSGrad 阶段具备更合理的 step acceptance control；随后用 L-BFGS + strong Wolfe line search 替代 Adam-only 的后期训练，以改善 ill-conditioned loss landscape 中的一阶优化停滞问题。

------------------------------------------------------------
1. 前阶段：Adam/AMSGrad + Trust Region
------------------------------------------------------------

前阶段仍然保留 Adam 或 AMSGrad，原因是 Adam 类一阶优化器适合训练初期的探索阶段。它不要求 Hessian 信息，计算成本较低，并且相比直接使用 quasi-Newton 方法，前期更不容易被 saddle point 吸引。

但不同于原始 Adam-only 方案，本方案不再使用 hard step guard retry，而是引入 trust region 机制控制每一步更新。

原始 hard step guard 的形式可以写为：

    accept if L_new <= L_old

其中：

    L_old：更新前的 rollout loss
    L_new：更新后的 rollout loss

该规则的问题是，它只判断 loss 是否上升，却不判断当前 step 是否与局部模型预测一致，也不区分“小幅可接受上升”和“破坏性 jump”。

trust region 的核心形式为：

    minimize_p m_k(p)
    subject to ||p|| <= Δ_k

其中：

    p：当前参数更新量
    m_k(p)：当前参数 θ_k 附近的局部近似模型
    Δ_k：trust region radius，即当前允许的最大更新半径
    k：训练迭代编号

更新是否被接受，不只看 L_new 是否小于 L_old，而是比较 actual reduction 和 predicted reduction：

    ρ_k = [L(θ_k) - L(θ_k + p)] / [m_k(0) - m_k(p)]

其中：

    ρ_k：实际下降量与预测下降量之比
    L(θ_k)：当前真实 loss
    L(θ_k + p)：更新后的真实 loss
    m_k(0)：局部模型预测的当前 loss
    m_k(p)：局部模型预测的更新后 loss

如果 ρ_k 较大，说明局部模型可信，接受更新，并可适当增大 Δ_k。
如果 ρ_k 较小或为负，说明当前 step 不可信，拒绝更新，并缩小 Δ_k。

因此，trust region 在本方案中的作用是：

    hard step guard retry
    →
    model-based step acceptance and radius adaptation

也就是说，它不是简单地“loss 变大就拒绝”，而是根据局部模型可信度决定是否接受 step 以及是否缩小/放大允许步长。

------------------------------------------------------------
2. 不提前进行 Adam learning-rate grid search 的处理
------------------------------------------------------------

Rathore et al. 的 Adam 阶段通过 grid search 选择 learning rate：

    η_Adam ∈ {10^-5, 10^-4, 10^-3, 10^-2, 10^-1}

并且在 Adam 阶段没有使用 line search；Adam 的 global learning rate 在进入 L-BFGS 之前保持为预设超参数。:contentReference[oaicite:1]{index=1}

本方案的不同点是：

    不提前进行 Adam learning-rate grid search

这样做的动机是，KFT 中每次完整 rollout training 成本较高，提前做大量 lr 搜索并不经济。因此，本方案让 trust region 在训练过程中承担一部分 step-size safety control 的功能。

换句话说，Adam 的 base learning rate 不再完全依赖外部 grid search，而是通过 trust region acceptance 来限制不可信更新：

    Adam proposes direction
    →
    trust region controls whether the update is acceptable

这里 Adam 负责给出更新方向，trust region 负责判断该更新在当前 ODE rollout loss landscape 中是否可信。

------------------------------------------------------------
3. 后阶段：L-BFGS + Strong Wolfe Line Search
------------------------------------------------------------

当 Adam/AMSGrad + trust region 阶段进入平台区后，切换到 L-BFGS。

切换动机来自 Rathore et al. 的结论：PINN loss 可能由于 differential operators 产生严重 ill-conditioning，而 quasi-Newton 方法可以改善问题的 conditioning；Adam + L-BFGS 通常比单独 Adam 或单独 L-BFGS 表现更好。:contentReference[oaicite:2]{index=2}

L-BFGS 阶段采用：

    L-BFGS + strong Wolfe line search

其中 L-BFGS 提供 quasi-Newton 搜索方向，strong Wolfe line search 负责选择合适 step size。作者也明确指出，L-BFGS 使用 strong Wolfe line search 是为了保持 L-BFGS 的稳定性。:contentReference[oaicite:3]{index=3}

该阶段的作用是：

1. 改善 Adam 后期在 ill-conditioned landscape 中收敛缓慢的问题；
2. 利用近似二阶信息修正 Adam/AMSGrad 的局部更新方向；
3. 用 strong Wolfe line search 控制 L-BFGS step size；
4. 替代 Adam-only 在后期长时间震荡或停滞的训练模式。

------------------------------------------------------------
4. line search 与 trust region 在本方案中的关系
------------------------------------------------------------

本方案中，trust region 和 line search 不同时用于同一个 optimizer step。

前阶段：

    Adam/AMSGrad + Trust Region

此时 trust region 替代 hard step guard retry，用于控制 Adam/AMSGrad 的更新是否可信。

后阶段：

    L-BFGS + Strong Wolfe Line Search

此时 line search 是 L-BFGS 的 step-size control 机制。

因此二者不是冲突关系，而是出现在不同阶段：

    前阶段：trust region controls Adam/AMSGrad updates
    后阶段：strong Wolfe line search controls L-BFGS updates

整体上，它们共同替代原本的：

    Adam/AMSGrad + hard step guard retry

------------------------------------------------------------
5. 与当前 Adam-only + hard step guard 的差异
------------------------------------------------------------

当前框架：

    Adam/AMSGrad
    +
    hard step guard retry

新框架：

    Adam/AMSGrad + Trust Region
    →
    L-BFGS + Strong Wolfe Line Search

核心差异包括：

1. step guard 从 hard rejection 变为 trust-region-based acceptance。
2. Adam 不再承担完整训练过程，而只作为前期探索阶段。
3. 后期由 L-BFGS 接管，以处理 ill-conditioned loss landscape。
4. L-BFGS 阶段使用 strong Wolfe line search，而不是 fixed step size。
5. 整体流程从 first-order-only 变为 first-order + quasi-Newton hybrid。

------------------------------------------------------------
6. 预期意义
------------------------------------------------------------

该方案的主要意义不是单纯提升 optimizer 复杂度，而是将当前 KFT 训练问题重新表述为：

    ill-conditioned ODE-constrained inverse problem

而不是：

    Adam learning rate tuning problem

或：

    KAN expressivity problem

在这个框架下，W0 训练结果不理想时，可以进一步区分：

1. Adam/AMSGrad 是否只是前期探索不足；
2. hard step guard 是否过于保守；
3. loss jump 是否来自 step size 与局部 curvature 不匹配；
4. L-BFGS 是否能在后期继续降低 rollout loss；
5. 如果 L-BFGS 后仍停滞，是否存在更深层的 under-optimization 或 model/input expressivity limit。

------------------------------------------------------------
总结
------------------------------------------------------------

本文构思的训练框架为：

    Adam/AMSGrad + Trust Region
    →
    L-BFGS + Strong Wolfe Line Search

其中：

    Adam/AMSGrad：负责前期探索；
    Trust Region：替代 hard step guard retry，控制前期 step acceptance；
    L-BFGS：负责后期 quasi-Newton fine-tuning；
    Strong Wolfe Line Search：控制 L-BFGS 阶段的 step size。

该方案与 Rathore et al. 的 Adam → L-BFGS 思路一致，但针对当前 KFT 中不希望提前进行 Adam learning-rate grid search 的实际限制，引入 trust region 作为 Adam 阶段的动态 step control 机制。

   - 使用固定 base lr。
   - 每一步由 backtracking alpha 决定 effective_lr = base_lr * alpha。

6. L-BFGS 阶段使用 strong Wolfe line search。
   - 这与两篇文献中常见的 L-BFGS 设置一致。
   - 但需要注意：第二篇文献指出 L-BFGS + strong Wolfe 可能提前停止，甚至在 gradient norm 仍不小的时候停滞。
   - 因此 L-BFGS 不是最终保证，而是 KFT 第一版 optimizer update 的合理第二阶段。

7. L-BFGS 阶段冻结 AGU。
   - 关闭 AGU 不能减少 L-BFGS closure 调用次数。
   - 关闭 AGU 是为了避免 closure 多次调用过程中 KAN grid 被改变，从而破坏同一个 optimizer step 内 loss landscape 的一致性。

8. basin hopping 暂不作为第一优先级。
   - 当前 KFT 已有 RS、多 trial、prerun 等 multi-start / preselection 机制。
   - 第一优先级是先把局部优化器从 legacy step guard retry 升级为更成熟的 optimizer pipeline。

因此，目前确定的 KFT-GBO 更新框架为：

    RS winner / manually selected trial
    →
    Adam/AMSGrad + monotone Armijo/backtracking
    →
    fixed epoch switch
    →
    freeze AGU
    →
    L-BFGS + strong Wolfe line search

第一版实现原则：

1. 只作用于 KFT-GBO。
2. 不动 RS。
3. 不动 prerun。
4. 不动 QCS。
5. 不动 AFM04 正式训练阶段。
6. 保留 legacy step guard 为可选开关。
7. 新机制作为 KFT-GBO 默认路径。
8. 第一版不允许 accepted loss jump。
9. 第一版不做 non-monotone line search。
10. 第一版不做自动 plateau 切换，Adam → L-BFGS 先使用固定 epoch。
