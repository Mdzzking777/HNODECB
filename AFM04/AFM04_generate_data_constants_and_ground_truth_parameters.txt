AFM04 generate-data constants and ground-truth parameters
=========================================================

Primary sources checked
-----------------------
1. Datageneration/DMT_KV/generate_trajectory_DMT_KV.py
   - This is the current AFM04 DMT-KV trajectory-generation script.
2. AFM04/test_case_settings/afm_dmt_kv_settings/afm_dmt_kv_model_settings.py
   - This mirrors the current AFM04 DMT-KV force-law settings.
3. AFM04/datasets/e0.0/data/*.npz
   - The generated dataset stores trajectories only; constants are not stored
     as separate npz keys.

Important note
--------------
The older Julia settings file contains an older Fad-style setting. The current
AFM04 generation script uses the DMT-KV force law with Hamaker constant A,
a0, beta, Estar, eta_star, ks, and cs. Therefore this note follows the current
Python generation script.

  Value: 1.9702184167723029e6

m

  Notion: tip radius
  Value: 1.0e-08

Fd

Ground-truth parameters requested
---------------------------------

Estar
  Notion: reduced/effective elastic modulus in the Hertz term
  Value: 1.5e7
  Unit: Pa

eta_star
  Notion: effective Kelvin-Voigt viscous coefficient in the contact term
  Value: 1.3
  Unit: Pa*s

ks
  Notion: sample Kelvin-Voigt spring stiffness in the x3 equation
  Value: 0.1
  Unit: N/m

cs
  Notion: sample Kelvin-Voigt damping coefficient in the x3 equation
  Value: 2.4e-07
  Unit: N*s/m

State-space equations used by the generation script
---------------------------------------------------

State:
  X = [x, v, y] = [x1, x2, x3]

Tip-sample gap:
  s = dist + x - y

Drive:
  F_drive(t) = Fd * cos(omega_d * t)

Tip equations:
  xdot = v
  vdot = (Fd * cos(omega_d * t) - k*x - c*v + F_ts) / m

Sample equation:
  ydot = x3dot

Contact/force closure:
  g(s) = sigmoid(beta * (s - a0))
  delta = max(a0 - s, 0)
  adhesion = -A*R / (6 * (g(s) * (s - a0) + a0)^2)
  F_Hertz = (4/3) * Estar * sqrt(R) * delta^(3/2)
  KV_coeff = eta_star * sqrt(R) * sqrt(delta)

  x3dot is solved explicitly from:
    x3dot = (-F_ts - ks*x3) / cs

  with:
    F_ts = adhesion + (1 - g(s))*F_Hertz + KV_coeff*(-v + x3dot)

  The generation script rearranges this as:
    x3dot = (-adhesion - (1 - g(s))*F_Hertz + KV_coeff*v - ks*x3)
            / (cs + KV_coeff)

  and then:
    delta_dot = x3dot - v, if delta > 0; otherwise 0
    F_ts = adhesion + (1 - g(s))*F_Hertz + KV_coeff*delta_dot
