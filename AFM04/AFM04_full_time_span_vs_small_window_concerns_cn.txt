AFM04：使用 full-time-span 与使用小时间窗口的焦虑点记录

一、问题背景

我们当前的 stage1pluslight（st1pl）、prestage2（prest2）、stage2light（st2l）主流程，
实际上都主要建立在较短窗口之上，尤其是 W1。

但这会带来一个长期没有被真正消解的结构性焦虑：

1. 如果改用第一次接触后的 full time span，训练与筛选的计算代价可能暴涨。
2. 如果继续只用一个小窗口，又会担心模型只学到了某一种局部接触阶段，
   无法覆盖“刚接触”和“成熟接触”之间明显不同的物理状态。


二、如果使用 full-time-span，会有什么焦虑

1. 运行成本暴涨
   当前 W1 长度约为 394 个采样点，而第一次接触后的 full post-contact horizon
   长度约为 110305 个采样点，量级上约为 280 倍。
   这意味着：
   - 单次 rollout / loss 计算成本会大幅增加
   - st1pl 的大规模 trial 筛选会首先变得极其昂贵
   - prest2 的多候选短程 GBO 试跑也会明显变慢
   - st2l 每个 epoch 的时间也会暴涨

2. 训练稳定性可能变差
   更长的时域意味着：
   - 数值积分区间更长
   - 误差更容易在时间上累积
   - adaptive lr、step guard、retry 等机制更容易被长时域误差触发
   - 优化过程不只是更慢，而且可能更不稳定

3. 早期阶段与晚期阶段被强行绑在一起
   full-time-span 会把：
   - 刚接触时的弱 Hertz / 强过渡 / 强敏感阶段
   - 成熟接触时的稳定 Hertz / 明显压入阶段
   放进同一个训练目标里。
   这可能使一个本来在某一局部 regime 表现不错的模型，
   被另一个 regime 的误差拖累。

4. st1pl / prest2 的角色会被破坏
   st1pl 和 prest2 的定位，本来更接近：
   - 用较轻的筛选代价快速区分候选
   - 先找出值得进入 st2l 的点
   如果直接让它们承担 full-time-span 的负担，
   整个分层流程的效率优势会大幅下降。

5. 即使付出高成本，也未必真正解决“缺失状态”的根问题
   即使使用 full-time-span，若 KAN 仍然只以 (x1, x2, x3) 为输入，
   而真实 F_ts 还依赖于更强的历史信息 / 粘弹性记忆 / sample-side velocity，
   则 full-time-span 只是把问题暴露得更完整，并不保证问题被根治。


三、如果继续只使用小时间窗口，会有什么焦虑

1. 刚接触与成熟接触并不是同一种局部物理状态
   刚接触时：
   - Hertz 接触项较弱
   - 黏附与过渡效应更重要
   成熟接触时：
   - Hertz / KV 响应更充分
   - 样品压入与恢复更明显
   因此，小窗口如果只取其中一种状态，就可能只学到一种局部规律。

2. 一个窗口无法“共情”另一个窗口
   如果模型只在 W1 上训练，
   那么它更可能学到“接触刚开始时”的局部有效力场；
   如果模型只在 W3 上训练，
   那么它更可能学到“成熟接触后”的局部有效力场。
   这会导致：
   - W1 上表现好，不代表 W3 上也好
   - W3 上表现好，不代表 W1 上也好

3. 当前 KAN 输入可能不是充分状态
   我们现在学习的是：
   F_ts = KAN(x1, x2, x3)

   但真实系统可能还依赖于：
   - x3dot
   - 接触历史
   - 粘弹性内部状态
   - 滞后/恢复信息

   若真实 F_ts 对这些量敏感，而它们没有进入输入，
   那么同一个 (x1, x2, x3) 在不同接触阶段，未必对应同一个 F_ts。
   换句话说：
   当前 KAN 所见状态，可能不是全局 Markov 的。

4. 小窗口可能把“多值映射”错看成“单值映射”
   在某一个短窗口内，
   F_ts 对 (x1, x2, x3) 的关系也许近似单值，因此模型可以拟合得很好。
   但一旦跨越多个接触阶段，
   不同 regime 的数据可能投影到相近的 (x1, x2, x3) 区域，
   从而形成全局上的“多值性”或“历史依赖性”。
   这会让小窗口训练产生一种虚假的安心感：
   - 在本窗口内很好
   - 但一跨窗口就失真

5. 对 x3、ks、cs 的恢复能力会受到窗口 regime 的影响
   当前已经观察到一种自洽现象：
   - 即使 ks、cs、x3 恢复不佳
   - 仍可能在局部窗口内恢复出看起来不错的 F_ts
   这说明模型可以在局部窗口里形成补偿解。
   这类补偿解在小窗口里可能看起来合理，
   但未必能推广到别的接触阶段。

6. 从“真实可获得信息”的原则上讲，W1/W2/W3 的真起点并不是天然可知
   这是一条非常重要但容易被忽略的边界：
   - 从物理定义上，真正可以被直接当作“第一次接触已知初值”的，
     只应是 literally 第一次发生接触的那个时刻，即约 235.136 μs 处。
   - 而 W1、W2、W3 的起点都发生在这之后，它们属于后续演化过程中的某个阶段，
     原则上并不自动拥有“真实状态已知”的特权。

   这意味着：
   - 如果后处理或可视化里把 W1/W2/W3 的真起点状态直接拿来当 rollout 初值，
     这在工程上也许方便，
     但在物理信息边界上属于额外假设。
   - 尤其是 W2、W3，它们更明显不是“第一次接触时的自然已知初值”，
     而是后验窗口。

   因此，我们需要清楚区分两件事：
   1. 为了诊断/可视化方便，采用窗口真起点做局部 rollout；
   2. 在原则上，系统真正可被赋予的已知初值，只是第一次接触处的真实状态。

   如果不把这条边界单独记住，就容易在方法论上高估
   小窗口局部 rollout 的物理合法性。


四、当前焦虑的本质

当前焦虑不是简单的“窗口选大还是选小”，而是一个更深层的结构问题：

1. 选 full-time-span：
   - 成本暴涨
   - 稳定性变差
   - 但信息更全

2. 选单个小窗口：
   - 成本可控
   - 训练容易聚焦
   - 但可能只学到局部 regime

3. 更深的根问题：
   即使窗口选择合理，只要当前 KAN 输入状态不足，
   模型仍可能无法用单一 F_ts(x1, x2, x3) 一致解释从接触起始到成熟接触的全部过程。


五、这份记录当前要表达的结论

目前我们面对的不是一个简单的工程参数调优问题，而是：

1. 计算代价约束
2. 接触阶段差异
3. 输入状态是否充分
4. 局部窗口可拟合性与全局可推广性之间的张力

它们共同构成了当前 AFM04 在 window design 上的主要焦虑来源。
